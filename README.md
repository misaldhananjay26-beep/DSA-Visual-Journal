# DSA Visual Journal

An interactive companion to a public DSA practice journal. The goal is to make algorithmic reasoning visible before implementation.

## Included

- Two Sum trace with complement lookup
- Binary Search explanation
- Sliding Window explanation
- Time and space complexity labels
- Interactive array highlighting
- Journal prompts that emphasize invariants and edge cases

This is a dependency-free prototype. Open `index.html` directly or serve the folder with a static server.

## Direction

Each visual should eventually link to a tested implementation, a short explanation, and one deliberate edge case. The project complements—not replaces—the readable solutions in the DSA journal.
